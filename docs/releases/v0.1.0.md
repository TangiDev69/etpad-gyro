# ETPad 0.1.0

The first public preview of ETPad: Wolfenstein: Enemy Territory on iPad,
built on ET: Legacy 2.86.2.

## What's in it

- **A native launcher.** Play Online, Practice with Bots and ET's own main menu,
  with How to Play and a ••• menu for match actions, settings and help.
- **Free game data in the app.** Download Free Game Data fetches Splash Damage's
  official free release, checks every file's SHA-256 and installs only
  `pak0.pk3`, `pak1.pk3` and `pak2.pk3`. Importing your own files from Files
  also works. No game data is in the IPA.
- **Who's Playing Now.** Live ET: Legacy servers from the official masters, with
  players, bots, map, version and ping. Tap to join, swipe to favorite, or join
  by address. Maps download on first join. Servers that need a mod with its own
  code can't be joined on iPad, and ETPad says so.
- **Practice with Bots.** Offline rounds on Oasis, Goldrush, Radar, Battery,
  Fuel Dump or Rail Gun with 5, 9 or 15 bots.
- **Touch controls built around ET's HUD.** An invisible floating move stick
  with push-to-sprint, look anywhere on the right, FIRE with slide-to-aim, and
  rings of action buttons. Size, opacity, look speed, left-handed layout and
  button positions are adjustable.
- **Controllers, keyboard and mouse.** Xbox, PlayStation and MFi controllers
  drive gameplay and ET's menus, with a quick-chat wheel on RB. Keyboard and
  mouse use ET's bindings with pointer lock in play. The app switches between
  inputs automatically. The iPad keyboard appears for ET's text fields and
  console.
- **External displays** follow the game window and use that screen's resolution.

## Install

Download `ETPad-unsigned.ipa` and sign it with your own Apple ID using
Sideloadly, AltStore or Xcode, or build your own copy with
[PadMint](https://github.com/chrissotraidis/padmint). Requires iPadOS 16 or
later. Bundle ID `com.chrissotraidis.etpad`, version 0.1.0 (1).

## Checked

- Development-signed build of this release on an iPad Pro 12.9-inch (6th
  generation): fresh install, missing-data screen, verified data detection, an
  offline Oasis round with active bots, and the live server list.
- Earlier builds on the same iPad: Oasis and Goldrush bot rounds, and a public
  server join with map download.
- PadMint player check (Apple Python 3.9, empty PadMint folder, fresh clone):
  passed, release gate PASS with 0 findings. The IPA passes `padmint audit`
  and ETPad's package audit.
